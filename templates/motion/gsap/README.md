# GSAP motion template

Source for `creator.py motion create`. Read [the authoring guide](../../../docs/GSAP.md) before editing. The template placeholders are filled by the first-party adapter; opening this source file directly is not the supported preview.

The generated `index.html` is standalone: exact GSAP runtime inline, system fonts, no CDN fetch. The timeline is finite/paused and registered by composition ID; showcase owns time during capture. Use `?render=1` for export. Default preview starts paused and includes Play/Pause, Reset and a keyboard-accessible scrubber.
